# Ejercicios de práctica de Python

Repositorio con los ejercicios que resolví mientras estudio Python como parte de la Tecnicatura en Ciencia de Datos e IA (Universidad del Gran Rosario). Cada archivo incluye el enunciado y mi solución.

## Temas

- **01-condicionales**: `if`, `elif`, `else`, operadores lógicos y validación de datos.
- **02-bucles**: `for`, `while` y bucles anidados.
- **03-listas**: crear, recorrer, filtrar y ordenar listas, y listas por comprensión.

## Ejercicios

### 01-condicionales
- `bienvenida_usuario.py`: saludo personalizado según el usuario.
- `contrasena_segura.py`: valida si una contraseña cumple requisitos.
- `potencia_par_impar.py`: indica si un número elevado a una potencia es par o impar.
- `division_numeros.py`: divide dos números y controla la división por cero.
- `login_contrasena.py`: login con dos intentos.
- `mayor_de_cuatro.py`: encuentra el mayor de cuatro números.
- `suma_de_tres_numeros.py`: comprueba si un número es la suma de los otros dos.
- `bot_trading.py`: indica comprar, mantener o vender según el precio.
- `asignacion_grupos.py`: asigna un grupo según género e inicial del nombre.
- `tributo_impuestos.py`: calcula el tipo impositivo según la renta anual.
- `hamburgueseria_pedido.py`: pedido de hamburguesa con ingredientes extra.

### 02-bucles
- `estrellas.py`: dibuja una figura de estrellas.
- `contrasena_bucle.py`: pide la contraseña hasta acertar.
- `palabra_al_reves.py`: muestra las letras de una palabra al revés.
- `contar_letras.py`: cuenta cuántas veces aparece una letra en una frase.
- `numeros_primos.py`: imprime los primos del 2 al 100.

### 03-listas
- `frutas_lista.py`: operaciones básicas con una lista.
- `lista_numeros.py`: filtrar, invertir y sumar una lista de números.
- `unir_listas.py`: une dos listas y las ordena.
- `segundo_mayor.py`: encuentra el segundo número más grande.
- `contar_mayores.py`: cuenta los números mayores que el ingresado.
- `suma_divisibles.py`: suma los números divisibles por el ingresado.
- `mayor_inferior.py`: encuentra el mayor número inferior al ingresado.
- `filtro_palabras.py` y `filtro_palabras_v2.py`: filtran palabras con letras prohibidas.

## Cómo ejecutarlos

1. Tener Python 3 instalado.
2. Descargar el repositorio o copiar el archivo que quieras probar.
3. Ejecutar en la terminal: `python nombre_del_archivo.py`
